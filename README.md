# Raz-e Penhan | Hidden Mystery

A simple, mobile-friendly **lateral thinking puzzle game** (situation puzzles).

Ask yes/no questions to solve mysterious situations. Supports **English** and **Persian (فارسی)**.

## Play

Just open `index.html` in any browser (works great on mobile).

Live demo (after enabling GitHub Pages):
**https://aigptdepai-collab.github.io/raz-e-penhan/**

## Features

- 5 classic + original mysteries
- Bilingual interface (EN / FA)
- Yes/No question system with keyword matching
- Clean dark mobile-first UI
- Fully client-side (no backend needed)

## How to play

1. Choose a mystery
2. Read the situation
3. Ask yes/no questions
4. Try to figure out the full story
5. Reveal the solution when ready
